第一步：创建 Supabase 数据库
免费 · 存储所有预约记录 · 约 10 分钟
⏱ ~10 分钟
Supabase 是什么？
免费的云数据库。每个学员预约后，信息自动存在这里。你可以随时查看全部记录，不会丢失。
  • 打开 supabase.com，点击 Start your project，用 GitHub 账号或邮箱注册（完全免费）
  • 登录后点击 New Project，填写：
    • Name：mandrix
    • Database Password：设一个密码（记住它）
    • Region：选 Singapore（最近）
    然后点 Create new project，等待约 2 分钟
  • 项目创建好后，点左侧菜单 SQL Editor，点右上角 New query
    把下面这段 SQL 全部粘贴进去，点 Run（绿色按钮）
    -- 在 Supabase SQL Editor 中运行这个文件： -- 文件位置：你的网站文件夹 / supabase-bookings.sql -- 用记事本或文本编辑器打开，复制全部内容，粘贴到这里运行
    💡 提示：supabase-bookings.sql 文件已经保存在你的网站文件夹里，用"文本编辑"打开，全选复制，粘贴到 SQL Editor 里运行。
  • 运行成功后，点左侧 Project Settings（齿轮图标） → API
    找到并复制这两个值，保存在备忘录里：
    名称在哪里找
    SUPABASE_URL Project URL 那一行（https://xxxxx.supabase.co）
    SUPABASE_SERVICE_ROLE_KEY service_role 那一行的密钥（点眼睛图标显示，点复制）
    ⚠️ service_role key 是私密密钥，不要分享给任何人

第二步：开通 Resend 邮件服务
免费 · 自动发送预约确认邮件 · 约 5 分钟
⏱ ~5 分钟
Resend 是什么？
免费邮件发送服务。学员提交预约后，系统自动给学员发确认邮件，同时给你发通知邮件。你完全不需要手动发。
  • 打开 resend.com，点 Get Started for Free，用邮箱注册
  • 登录后，左侧菜单点 API Keys，点 Create API Key
    名称填 mandrix，权限选 Full Access，点 Add
  • 复制生成的 API Key（以 re_ 开头），保存在备忘录里
    ⚠️ 这个 Key 只显示一次，务必立刻保存！
    变量名：RESEND_API_KEY
  • （可选但推荐）验证你的域名，让邮件从 noreply@mandrix.top 发出，而不是默认地址
    左侧点 Domains → Add Domain → 输入 mandrix.top → 按提示在你的域名 DNS 里添加记录
    💡 如果觉得麻烦，可以先跳过这步，系统会用 Resend 的默认地址发邮件，功能一样正常。

第三步：在 Vercel 填入所有密钥
把三个密钥填进去，系统立刻激活 · 约 5 分钟
⏱ ~5 分钟
Vercel 是什么？
你的网站 mandrix.top 就托管在 Vercel 上。在 Vercel 设置里填入密钥，网站就能连上数据库和邮件服务。
  • 打开 vercel.com/dashboard，找到你的 mandrix-display-site 项目，点进去
  • 点顶部 Settings 标签 → 左侧菜单点 Environment Variables
  • 逐一添加以下 4 个变量（每次点 Add New，填 Key 和 Value，点 Save）：
    Key（变量名） Value（填什么）
    SUPABASE_URL 从第一步 Supabase 复制的 Project URL
    SUPABASE_SERVICE_ROLE_KEY 从第一步 Supabase 复制的 service_role key
    RESEND_API_KEY 从第二步 Resend 复制的 API Key（re_开头）
    ADMIN_TOKEN 自己设一个密码（例如：Mandrix2026!），用于进入管理后台
  • 4 个变量全部添加完成后，点左侧 Deployments，找最新一次部署，点右边 … → Redeploy
    等待约 1 分钟，部署完成后自动化系统即刻激活 ✅
